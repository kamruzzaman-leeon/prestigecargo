# Prestige Cargo - Freight Forwarding & Transport Solutions

Prestige Cargo is a modern web application and logistics platform for a licensed Freight Forwarding & Customs Clearance (C&F) agency in Bangladesh.

## Features
- **Dynamic Logistics Interface**: Interactive animations, real-time vehicle routes, and glowing flight pulse radar animations.
- **Hero & Banner Aircraft Animations**: Cargo airplane flying across the hero section and page banners (About, Services, Tracking, Contact).
- **Service Catalog**: Air freight, Ocean container shipping, inland trucking, warehousing, and customs clearance.
- **Real-Time Shipment Tracking**: Interactive AWB / container status tracker.
- **Instant Freight Quote Generator**: Modal & inline quote estimators with Web3Forms notification integration.
- **Admin Dashboard**: Secure management of shipment records, inquiries, and content.

## Tech Stack
- **Frontend**: React, Vite, Lucide Icons, Vanilla CSS
- **Backend / API**: Node.js, Express, MongoDB (with JSON local fallback)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Install frontend dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build
```

### Environment Variables
Copy `.env.example` to `.env` and configure your settings:
```bash
cp .env.example .env
```
